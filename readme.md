# ResearchPilot API — Autonomous Document Research Engine

This workspace contains the complete full-stack repository for **ResearchPilot API**, an autonomous document research engine built with Python, FastAPI, ChromaDB, SQLAlchemy, LangGraph/LangChain, Celery, Redis, and Next.js 14.

## 📁 Full-Stack Repository Structure

```
ResearchPilot API/
├── backend/               <-- FastAPI Backend Engine (Gunicorn/Uvicorn, LangGraph, Celery)
│   ├── app/
│   ├── .env
│   ├── Dockerfile
│   ├── docker-compose.yml
│   └── README.md
├── frontend/              <-- Next.js 14 React Dashboard (SSE Stream, Dropzone, Tailwind)
│   ├── src/
│   ├── package.json
│   └── README.md
├── .gitignore
└── readme.md
```
