# ResearchPilot API — Autonomous Document Research Engine

This workspace contains the complete full-stack codebase for **ResearchPilot API**, an autonomous document research engine built with Python, FastAPI, ChromaDB, SQLAlchemy, LangGraph/LangChain, Celery, and a Next.js 14 React frontend.
